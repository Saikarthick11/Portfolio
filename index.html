# projects

Things I've shipped.

Grad-school infra and AI work, plus a couple of earlier academic builds.

Agentic Student Survey Management System
centerpiece project

A production-grade agentic AI platform, not a class script — a decoupled microservices architecture with a stateful LLM agent, a custom MCP tool backend, and a Kubernetes-orchestrated deployment.

  • Built a stateful conversational intake agent with LangGraph and the Gemini API, orchestrating multi-turn field collection and structured batch parsing through a defined agent workflow.
  • Implemented a secure remote MCP backend with FastAPI — discovery-based tool integration over SSE transport — so the agent could dynamically invoke backend capabilities across distinct cluster pods.
  • Built a natural-language-to-SQL query engine with SQLModel and PyMySQL, with a strict delete-safety policy in the agent graph that intercepts destructive requests and requires explicit user confirmation.
  • Built the React frontend and deployed the full system as a multi-tier, decoupled microservices architecture on a single-node RKE2 Kubernetes cluster hosted on AWS EC2.
