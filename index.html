Production Cloud Deployment Platform

devops · gitops

An automated pipeline to test, package, deploy, and monitor a Python application. The app is a small FastAPI API — the real focus is the infrastructure and delivery process around it: a repeatable release path that checks changes first, keeps deployment settings in Git, and makes application health visible.

  • CI pipeline: GitHub Actions runs tests, builds Docker images for AMD64 and ARM64, and scans them with Trivy before publishing to GitHub Container Registry.
  • GitOps deployment: Argo CD watches the Helm configuration in Git and keeps the local Kubernetes deployment aligned with it.
  • Monitoring: Prometheus and Grafana track request activity, CPU and memory usage, pod restarts, and available replicas.
  • Reliability exercises: CPU autoscaling on a separate practice app (1 → 3 pods under traffic, then back to 1), automatic pod replacement, and a Helm rollback after a deliberately bad release — existing pods stayed ready throughout.
  • Cloud infrastructure: Terraform provisions GCP networking, a GKE cluster, node permissions, and an Artifact Registry repository. The app ran on a 2 vCPU / 8 GB GKE worker with all three API endpoints verified, and the resources were deleted afterward with an inventory check confirming cleanup.

Scope: automated GitOps and Grafana monitoring were demonstrated locally; the GCP deployment was a separate Terraform-and-Helm exercise using the existing GHCR image. A learning project, not a production service.

Agentic Student Survey Management System

AI application

A conversational survey application that collects structured responses and supports natural-language queries. It combines a stateful agent, a custom MCP backend, and a React interface.

  • Built a stateful conversational intake agent with LangGraph and the Gemini API, orchestrating multi-turn field collection and structured batch parsing through a defined agent workflow.
  • Implemented a remote MCP backend with FastAPI — discovery-based tool integration over SSE transport — so the agent could dynamically invoke backend capabilities across distinct cluster pods.
  • Implemented a natural-language-to-SQL query engine with SQLModel and PyMySQL, with a strict delete-safety policy in the agent graph that intercepts destructive requests and requires explicit user confirmation.
  • Built the React frontend and deployed the full system as a multi-tier, decoupled microservices architecture on a single-node RKE2 Kubernetes cluster hosted on AWS EC2.

Job Alert Bot

automation

An automated job search tool that filters new US roles, sends email alerts, and logs matches to a searchable dashboard. Employer boards are checked roughly every five minutes; other sources use longer intervals.

  • Serverless by design: a GitHub Actions cron job runs the bot with no server or database — it commits its dedupe file and job log back to the repo, so Git is the datastore and the dashboard reads the same JSON.
  • Smart filtering: keeps target roles, drops senior titles, and handles tricky location collisions (DE, IN, CA, and "India" inside "Indianapolis"), tested against 30+ real location strings.
  • Built for free tiers: batched Adzuna queries, 15-minute intervals for several aggregators, and four daily Remotive checks respect source-specific limits; credentials live in GitHub Secrets.
